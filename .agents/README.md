# `.agents` 工作规则导航

根目录 `AGENTS.md` 是自动入口，本目录是详细规则库。AI 不应假设工具会自动读取 `.agents/`，而应由根入口按任务类型显式路由。

## 文件职责

| 文件 | 适用任务 | 核心目标 |
| --- | --- | --- |
| `resource-boundaries.md` | 命令、服务、容器、压测、后台任务 | 防止资源失控和残留进程 |
| `testing-workflow.md` | 单测、集成测试、实测、压测 | 让验证等级与结论严格对应 |
| `rag-workflow.md` | RAG、向量库、模型、Agent | 保持数据链路、评测和安全边界清晰 |
| `backend-reliability.md` | RocketMQ、Outbox、幂等、一致性 | 统一可靠消息设计与验证口径 |
| `delivery-checklist.md` | 所有文件修改和交付 | 控制范围并完整交付 |

## 使用规则

1. 每次先阅读根目录 `AGENTS.md`，再读本文件和命中的专题文件。
2. 同一任务命中多个专题时全部读取。例如修改 RAG 的 RocketMQ 索引消费者，需要同时读取 RAG、后端可靠性、测试和交付规则。
3. 本目录记录稳定方法，不记录临时进度、私人规划或个人材料。
4. 新规则应短小、可执行、可验证，避免复制大段任务清单。

## 默认工作方式

- 先检查现状和已有证据，再决定是否修改。
- 优先静态检查和低资源测试；真实依赖验证必须有明确目的、边界和清理方案。
- 一次只推进一个可验收增量，不静默扩大任务范围。
- 不把跳过、超时、Mock 或仅编译通过描述成真实链路成功。
- 用户要求停止时，停止比补完当前步骤优先。
